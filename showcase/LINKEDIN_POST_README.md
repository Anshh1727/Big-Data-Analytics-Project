## Post text

I’ve completed an end-to-end HR analytics project using PostgreSQL, R, and Tableau Public.

The project uses an instructor-approved **synthetic** employee dataset, so the results are educational and should not be treated as findings about a real employer.

I built a PostgreSQL data-cleaning and analytics pipeline, explored the data in R, evaluated an attrition model, and created three interactive Tableau dashboards: Workforce Overview, Attrition & Performance, and Compensation Equity.

One important result: the attrition model showed no useful predictive signal (held-out ROC-AUC 0.494; PR-AUC 0.097 versus 0.100 resignation prevalence). I documented why it should not be used to make decisions about employees. The compensation analysis also has clear limits because the data is synthetic and its salary units and currency are unspecified.

This project helped me practice the full analytics workflow—from validation and SQL transformations to model evaluation and communicating results responsibly.
