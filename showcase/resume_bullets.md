# Resume project entry

**End-to-End HR Predictive Analytics & BI Dashboard | SQL, R, Tableau, Advanced Modeling**  
GitHub repository: https://github.com/Anshh1727/Big-Data-Analytics-Project
Tableau Public: https://public.tableau.com/app/profile/anshu.lihitkar/viz/HRAnalyticsWorkforceAttritionCompensation/CompensationEquity

- Built a reproducible PostgreSQL ETL and analytical-view pipeline for 100,000 synthetic employee records; validated 20 source fields, unique employee keys, one-to-one subject-area tables, and zero row/compensation reconciliation differences.
- Conducted R EDA and evaluated a cross-sectional logistic classifier (held-out ROC-AUC 0.494; PR-AUC 0.097 vs 0.100 prevalence); documented why it should not be used for employee decisions.
- Modeled compensation with 100,000 observations (holdout MAE 95.03 in unspecified source units) and created aggregate-only exports/specifications for three Tableau dashboards.

Accuracy note: Three Tableau dashboards are published with visible navigation tabs. The dataset is synthetic and instructor approval was user-confirmed.
